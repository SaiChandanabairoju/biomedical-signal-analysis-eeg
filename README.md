# Biomedical Signal Analysis Using EEG Data

## Project Overview

This project analyzes EEG-derived biomedical signal features for emotion-related analysis.

## Dataset

The project uses the EEG emotion dataset containing numerical EEG-derived features and three emotion classes:

- NEGATIVE
- NEUTRAL
- POSITIVE

## Objectives

1. Understand the EEG dataset.
2. Perform data quality assessment.
3. Analyze missing values and duplicates.
4. Detect statistical outliers.
5. Explore EEG-derived features.
6. Perform correlation analysis.
7. Visualize feature distributions across emotion classes.
8. Apply PCA for dimensionality analysis.
